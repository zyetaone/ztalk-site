Documentation

zTalk documentation

Everything needed to install zTalk, get dictation pasting by itself, and run meetings, notes and integrations. zTalk is internal software for Zyeta: every feature is included, there are no plans, no licences to buy and no trial limits.

Install

macOS (Apple silicon)

  1. Download the .dmg from the download page.
  2. Open it and drag zTalk into Applications.
  3. The build is signed ad hoc, not notarised, so the first launch needs right-click → Open once. Gatekeeper then stops asking.
  4. Grant the two permissions below before the first dictation.

Windows 10 and 11 (x64)

  1. Run zTalk-win-x64.exe.
  2. SmartScreen: More info → Run anyway.
  3. It installs per user and starts automatically; no administrator rights needed.

Android 10 and newer

  1. Copy the .apk to the phone and tap it.
  2. Allow installing from this source when Android asks.
  3. Set zTalk as the keyboard when onboarding offers it.

Permissions

zTalk has no way around these two grants; macOS enforces them for any app that listens or types on your behalf.

Microphone

Asked on the first dictation. Without it zTalk records nothing, and the audio meter in the panel stays flat.

Accessibility

Needed to insert text into other apps. Without it zTalk still transcribes and copies the text, but it cannot paste, so you would press ⌘V yourself.

  1. Open System Settings → Privacy & Security → Accessibility.
  2. If zTalk is listed, switch it on. If it is not, click + at the bottom of the list, choose Applications → zTalk and open it. Dragging the app into the list from Finder works too.
  3. Quit zTalk completely from the menu bar and reopen it.

Each macOS build is signed with its own identity, so an update can reset this grant. After installing a new version, check that zTalk is still switched on in that list.

Auto-paste: make dictation fill the field

When everything is right, you press the hotkey, speak, press it again, and the text appears at the cursor in whatever app you were using.

If the text lands in the clipboard but not in the field

  1. Check Accessibility. Settings → Privacy & Data in zTalk shows the live state; it must read “Granted”. Granting it while zTalk is running is not enough — quit and reopen the app.
  2. Remove stale entries. If Accessibility lists more than one zTalk, or an “Electron” entry, remove them with −, add /Applications/zTalk.app again and restart.
  3. Run it from Applications. If you launched zTalk from the mounted disk image, macOS ties the grant to that temporary path. Move the app to Applications first.
  4. Keep AI cleanup off unless a model is configured. Cleanup on with no model produces a “Cleanup failed” card; the raw transcript still goes out, but the card is noise. Settings → AI Models → Dictation Cleanup.

A refused paste is recorded in zTalk's log, which is the fastest way to tell a missing permission apart from a focus problem. Ask IT for the log if the steps above do not fix it.

Dictation

  • Dictation hotkey — press once to start, once to stop. The text is pasted at the cursor, or copied when no writable field has focus.
  • Translation hotkey — dictate in one language, paste in another. Pick both in Settings → Hotkeys.
  • Voice assistant hotkey — sends what you say to your AI assistant as a command; highlighted text is edited in place.
  • Panel — the floating control panel starts and stops dictation by click, and shows the live transcript. It stays click-through except where there is a control.

Meetings and notes

  • zTalk detects Zoom, Teams and FaceTime calls and starts transcribing them without joining as a participant.
  • Speaker diarization and voice fingerprints run locally, so names stay on the device.
  • Notes support folders, semantic search, sharing and AI actions.
  • Calendar integration links meetings to events (see below).

Models

  • Whisper — 99 languages, runs locally on CPU, Metal, CUDA or Vulkan.
  • NVIDIA Parakeet — fast English transcription.
  • zVoice — multilingual model for dictation on weaker hardware.
  • Cohere Transcribe — multilingual alternative.
  • zTalk Cloud — optional; nothing is sent unless you choose it.

Models download once and are stored in ~/.cache/ztalk on macOS and Linux.

Updates

zTalk checks for updates at launch and every four hours. When one is available the app offers it; macOS verifies the download against the published checksum and replaces the bundle itself, Windows runs the installer on quit.

Because macOS builds are signed ad hoc, an update can reset the Accessibility grant. Re-check that step after a version change.

Troubleshooting

No text appears, but the transcript was saved

That is the Accessibility grant; see auto-paste.

“Cleanup failed — AI cleanup is on, but no cleanup model is set up”

Cleanup needs a language model. Either configure one under Settings → AI Models, or turn cleanup off. Your dictation works either way.

The microphone meter stays flat

The microphone permission was denied. System Settings → Privacy & Security → Microphone → enable zTalk, then restart it.

zTalk opens with “damaged” instead of “unidentified developer”

That build was signed incorrectly. Download the current installer again; releases are re-signed so they open.

For administrators

  • Installers and update metadata are published to the public zyetaone/ztalk-downloads repository, so installed copies update without a token.
  • Source and release pipeline live in zyetaone/ztalk (private).
  • A version tag builds macOS and Windows and publishes the installers; Android is built locally. Publishing from CI needs the ZTALK_DOWNLOAD_TOKEN secret.
  • To move downloads to your own storage (R2, S3, a CDN), the only change is the download host in the site config and the updater feed.
